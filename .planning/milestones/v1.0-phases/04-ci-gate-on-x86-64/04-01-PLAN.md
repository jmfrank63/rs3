## Phase Goal

**As a** maintainer of rs3, **I want to** gate every push with a GitHub Actions workflow on an x86_64 runner that fails on any fmt, clippy or test failure, **so that** regressions and x86-only V8 crashes are caught before they land.

This plan is the **gate slice**. The archived actions-rs workflow is replaced by one `ci.yml` whose job sequences scripts that also run locally: repo guards, fmt, clippy, test, the release build and the release smoke. The tracer (Task 1) wires the whole workflow end to end, with the workflow-hygiene guard (g) and a release smoke that answers `GET /`, and proves it by replaying every `run:` line locally. Task 2 adds the other seven policy guards and a planted-violation self-test proving each one fails loudly. Plan 04-02 then grows the smoke into the JS/V8 evidence and hands the remote x86_64 run to the operator.
